# 도원 (Peach Garden)

촉한 시점의 삼국지 전술 RPG입니다. 모바일 브라우저에서 세로 화면으로 플레이합니다.
Into the Breach처럼 적의 공격이 미리 보이고, 결과가 운에 좌우되지 않는 결정론적 전투를 합니다. 쓰러진 장수는 영구 전사합니다.

- 설계 문서: [docs/design.md](docs/design.md)
- 현재 구현 범위: 1장 1화 「탁현 출정」

## 조작
1. 장수를 탭해 선택합니다.
2. 파란 칸을 탭해 이동합니다.
3. 붉은 테두리의 적을 탭하면 공격 결과를 미리 봅니다. 같은 칸을 한 번 더 탭하면 공격합니다.
4. 붉게 칠해진 칸은 적이 다음 턴에 공격할 곳입니다. 그 칸을 비우거나, 적을 밀어내서 공격 방향을 바꾸세요.

## 개발
```bash
npm install
npm run dev     # 같은 Wi-Fi의 폰에서는 터미널에 표시되는 Network 주소로 접속
npm test        # 전투 규칙 단위 테스트 (Vitest)
npm run build   # 타입 체크 + 빌드
```

## 구조
```
src/core/    전투 규칙 순수 로직 (Phaser 의존 없음, 테스트 대상)
src/data/    장수, 시나리오 (맵, 배치, 대사, 목표)
src/scenes/  타이틀, 이야기, 전투, 결과 화면
tests/       Vitest 단위 테스트
```
