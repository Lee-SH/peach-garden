# 도원 (Peach Garden)

촉한 시점의 삼국지 RPG입니다. 모바일 브라우저에서 세로 화면으로 플레이합니다.
에픽세븐처럼 속도 기반 턴제로 싸우고, 자동 전투를 지원합니다. 한 무리를 쓰러뜨리면 다음 무리를 향해 달려갑니다. 출진 전에 진형(선봉, 중군, 후군)을 정합니다.

- 플레이: https://lee-sh.github.io/peach-garden/
- 설계 문서: [docs/design.md](docs/design.md)
- 개발 노트 (판단 기록): [docs/dev-notes.md](docs/dev-notes.md)
- 현재 구현 범위: 1장 황건적의 난 (6화, 탁현 출정 ~ 천공장군 장각)

## 플레이 방법
1. **진형**: 장수를 탭해 고른 뒤 다른 자리를 탭하면 서로 바뀝니다. 선봉은 많이 때리고 많이 맞으며, 경험치를 가장 많이 받습니다.
2. **전투**: 자동 전투가 기본으로 켜져 있습니다. 자동을 끄면 자기 차례에 스킬을 고르고 적을 탭해 공격합니다.
   필살기는 기세 게이지(체력 바 아래의 노란 줄)가 가득 찼을 때 쓸 수 있습니다.
3. **영구 사망**: 승리한 전투에서 쓰러진 장수는 전사 처리됩니다. 유비가 쓰러지면 패배하고, 진형을 바꿔 다시 도전합니다.

## 개발
```bash
npm install
npm run dev     # 같은 Wi-Fi의 폰에서는 터미널에 표시되는 Network 주소로 접속
npm test        # 전투 규칙 + 난이도 회귀 테스트 (Vitest)
npm run build   # 타입 체크 + 빌드
```
`main` 브랜치에 push하면 GitHub Pages로 자동 배포됩니다.

## 구조
```
src/core/combat.ts    전투 규칙 (행동 게이지, 스킬, 진형, 경험치)
src/core/simulate.ts  자동 전투 시뮬레이터 (난이도 조정용)
src/data/             장수, 적, 시나리오 (무리 구성, 대사)
src/scenes/           타이틀, 이야기, 진형, 전투, 결과 화면
tests/                단위 테스트 + 난이도 회귀 테스트
```
